# 로그인 시작 화면 검증 — 2026-10-15

## 변경

- Discord 공식 브랜딩 가이드의 Blurple 버튼 스타일과 흰색 심볼을 적용하고 문구를 `Discord로 시작하기`로 변경했다.
- 카드 제목을 큰 가운데 정렬 `LLVY`로 정리하고 기존 제목·안내 문장을 제거했다.
- 두 버튼 사이에 위아래 24px 여백과 가는 구분선, `아직 모임원이 아니라면?` 문구를 추가했다.
- Discord 로고 없는 연한 보라색 `가입하기` 링크를 추가했다. 기본값은 지정된 소모임 페이지이며 서버 환경변수 `MAIN_SIGNUP_URL`로 변경한다.
- 빈 값·잘못된 URL·HTTP(S) 이외의 스킴·사용자명이나 비밀번호가 포함된 URL은 기본값으로 대체한다. `.env.example`, 운영 안내와 OpenSpec에 계약을 반영했다.

## 결과

- Node 24.21.0에서 최종 `npm run check` 통과: 50개 테스트 파일 통과, 4개 건너뜀; 테스트 798개 통과, 71개 건너뜀. lint·타입·production build·포맷 검사 통과.
- `openspec validate --all --strict` 24개 통과. `git diff --check` 통과.
- 로컬 production 서버에서 1280px·320px 화면을 확인했다. 320px에서 가로 넘침이 없고 두 버튼과 구분 문구가 각각 한 줄로 표시된다.
- 키보드 Tab으로 두 동작에 순서대로 접근할 수 있고 3px 포커스 테두리가 표시된다. 실제 버튼 높이는 50px이며 Discord 심볼은 보조기기에 중복 노출되지 않는다.
- 동일 빌드를 각각 기본 설정, `MAIN_SIGNUP_URL=https://example.com/join?source=llvy`, 잘못된 URL 설정으로 실행해 렌더링된 가입 링크가 기본값·지정값·기본값으로 표시되는 것을 확인했다.
- 공식 흰색 SVG의 경로가 원본과 정확히 일치함을 비교했다. 로고는 외부 요청 없이 인라인으로 표시된다.
- 최종 소스 검토에서 기존 GET 로그인 경로·내부 목적지 정제 유지, 가입 링크의 폼 밖 배치, 로그인 화면에 한정된 CSS 적용을 확인했다.

## 범위

로컬 화면과 링크 설정을 검증했다. 실제 Discord OAuth 완료, 소모임 가입 제출, 운영 환경변수 변경과 배포는 이번 검증에 포함하지 않았다. 별도 PostgreSQL·Redis·실제 리플레이 환경이 필요한 테스트는 기본 검사에서 건너뛰었다.
