# 문서 유지관리 지침 검증

검증일: 2026-10-18. 범위: 네 저장소의 문서 갱신 지침·색인·템플릿과 문서 관리 명세.

## 내용 대조

| 사례                     | 확인한 지침                                                                         |
| ------------------------ | ----------------------------------------------------------------------------------- |
| desktop API 변경         | LLVY 원본·OpenSpec → 앱 고정 사본 별도 검토 → 위키 업로더·구조 요약의 순서와 소유권 |
| 환경변수·명령 변경       | 소유 저장소의 실제 설정·스크립트, README·개발·배포 안내와 연계 위키의 갱신 대상     |
| 문서 추가·이동·제목 변경 | README·llms.txt·출처 목록·들어오는 링크·앵커·중요 변경 기록의 확인 절차             |
| 문구만 수정              | 외부 사실 확인일과 검증 상태를 임의로 올리지 않는 규칙                              |
| 기술 결정 기록           | 기술 사실·이유·범위를 남기는 공개 문서 작성 기준                                    |
| 형제 저장소 부재         | 로컬 작업 진행과 대상 저장소·문서·수정 내용·미완료 이유 기록, 동기화 완료 주장 금지 |

## 검사 결과

- 지침·색인·계획 산출물 15개에서 로컬 링크 82개의 대상을 확인했다. 해당 링크에 제목 앵커는 없었다. 문서 형식과 후행 공백 검사를 통과했다.
- LLVY OpenSpec strict 30/30, Worker 2/2, 업로더 1/1을 통과했다. 구조 검사와 별도로 위 사례 및 델타 요구사항을 문서 내용과 대조했다.
- 변경 전 파일 해시와 대조해 코드·의존성·설정의 실행 값·기존 기능 명세 및 작업 목록에 변경이 없음을 확인했다. 서버 기능은 0/36, 업로더는 0/34로 유지했다.
- 공개 문서의 개인 식별값·홈 경로 형태 검사와 네 저장소의 `git diff --check`를 통과했다.

문서만 변경했으므로 런타임 테스트·배포·Windows·외부 서비스 검증은 수행하지 않았다. 자동 문서 동기화나 CI 링크 검사 기능을 추가한 결과도 아니다.

## 아카이브

[문서 관리 변경](../../openspec/changes/archive/2026-10-18-define-documentation-maintenance/)의 작업 6개를 완료하고 [정식 명세](../../openspec/specs/documentation-maintenance/spec.md)에 요구사항 4개를 반영했다. 기존 서버·업로더 기능 변경은 열린 상태로 유지한다.
