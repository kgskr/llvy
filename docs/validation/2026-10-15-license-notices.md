# 라이선스와 외부 자료 고지 검증 — 2026-10-15

## 변경

- 자체 코드와 문서에 PolyForm Noncommercial 1.0.0을 적용했다. 적용 범위는 프로젝트 기여자가 실제로 보유하고 허가할 수 있는 권리로 한정했다.
- Riot Games 자료, Discord 공식 로고, 외부 패키지와 Unicode 데이터, 모임원이 제공한 AI 생성 배너를 자체 코드 라이선스에서 제외했다. 배너의 LLVY 사용 허락을 제3자의 수정·재배포 허락으로 확대하지 않았다.
- README와 패키지 메타데이터에 라이선스를 표시하고, `THIRD_PARTY_NOTICES.md`에 출처와 별도 이용 조건을 정리했다.
- 공통 루트 레이아웃에 Riot 비공식 고지를 추가했다. 로그인 화면과 인증 후 화면에 같은 고지가 표시되도록 하고, 짧은 화면에서도 하단에 배치하도록 공통 레이아웃을 조정했다.

## 검증

- Node 24.21.0의 `npm run check`: 테스트 파일 52개 통과·4개 건너뜀, 테스트 818개 통과·72개 건너뜀. lint·타입·production build·전체 포맷 검사 통과.
- `openspec validate --all --strict`: 25개 통과. 기능·권한·데이터 계약 변경은 없으며 기존 명세와 충돌하는 내용을 발견하지 않았다.
- 공식 사이트에서 받은 PolyForm 원문과 `LICENSE`의 원문 부분이 바이트 단위로 일치함을 확인했다. 프로젝트 적용 범위와 필수 고지는 원문 앞에 별도로 두었다.
- `package.json`과 `package-lock.json` 루트의 라이선스 식별자 일치를 확인했다.
- 로컬 production 서버의 로그인 화면을 브라우저에서 확인했다. 기존 로그인·가입 동작과 별도인 하단에 한국어 안내, 영문 고지, Riot 정책 링크가 표시된다.
- 1차 자체 검토에서 Discord 공식 로고의 외부 자료 안내 누락을 발견하여 LICENSE·README·외부 자료 안내에 보완했다. 2차 자체 검토에서 적용 범위·원문 보존·공통 고지·문서 링크와 최종 변경을 다시 확인했다.
- 문서 보완 후 포맷과 `git diff --check`를 다시 확인했다.

## 범위

실제 PostgreSQL·Redis·개인 리플레이가 필요한 선택 검사는 설정이 없어 건너뛰었다.
이번 변경에는 DB 마이그레이션, 환경변수·캐시 활성화·인증 로직 변경이 없다.
위 결과는 로컬 검증이며, 운영 배포와 해당 커밋의 도메인 반영은 별도로 확인해야 한다.
이 검증은 법률적 적합성, Riot 제품 등록·승인, AI 산출물의 권리 보유를 확정하지 않는다.
