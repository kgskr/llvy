# 모임원 목록 검색 검증 — 2026-10-15

## 변경

- `/members`의 `모임원 정보` 제목 옆, 상단 모임원 메뉴 아래쪽에 `이름 또는 라이엇 ID` 검색바를 배치했다. 설명은 아래 행에 두고 관리 버튼은 오른쪽에 유지한다.
- 기존 인증·권한 투영을 거친 전체 모임원과 연결 계정을 클라이언트 컴포넌트로 전달한다. 입력마다 이름이나 연결된 모든 계정의 표시 라이엇 ID에 검색어가 포함되는지 확인한다.
- NFC, 양끝 공백, 영문 대소문자를 정규화하고 `%`, `_`, `#`는 일반 문자로 처리한다. 한 모임원은 한 번만 표시하며 기존 순서와 모든 계정을 유지한다.
- 빈 검색어는 전체 목록을 복원한다. 검색 결과 없음과 등록 모임원 없음을 구분하고 접근 가능한 검색 입력 및 결과 수 상태 안내를 제공한다.
- 검색에는 API·DB 호출이나 페이지 이동이 없다. 상세/관리 링크는 자동 prefetch를 끄고 클릭 시 이동한다. 기존 서버 조회·캐시·권한·메인 검색 계약은 유지한다.

## 자동 검증

- Node.js 24.21.0에서 `npm run check` 통과: 53개 파일 통과, 선택 검사 파일 4개 생략; 테스트 837개 통과, 72개 생략. lint, typecheck, production build, format 모두 통과했다.
- 별도 집중 검사 31개 통과: 새 필터 14개와 기존 역할별 개인정보·페이지 표시 17개. 이름 중간 일치, 계정 없는 모임원, 동명이인, 두 번째 계정, 태그/전체 ID, 여러 계정 중복 방지, NFC/대소문자/공백, 특수문자, 목록 복원, 생년 검색 제외를 확인했다.
- `openspec validate --all --strict`: 아카이브 전후 각각 26개 통과.
- `git diff --check` 통과. Next.js 설치 문서의 서버/클라이언트 경계 및 React 검토 스킬 기준으로 props 투영, 단일 state, 파생 필터 결과와 접근성을 점검했다.

## 브라우저 검증

실제 `MemberList`, 필터, `next/link`, CSS를 esbuild로 묶은 임시 합성 데이터 페이지를 인앱 브라우저에서 확인했다. 내비게이션은 기존 마크업을 재현했다.

- `나다` 입력 시 4명 중 3명 표시, `  PLAYER#alt  ` 입력 시 보조 계정이 일치하는 1명과 그 모임원의 모든 계정 표시.
- Enter를 눌러도 URL과 화면을 유지한다. `없는이름` 입력 시 결과 없음과 0명 안내, 검색어 삭제 시 원래 4명과 순서 복원.
- 초기 로딩 후 위 입력·Enter·삭제 동안 로컬 HTTP 서버에 추가 요청이 없었다. 코드에도 fetch, Server Action, 라우터 호출이 없다.
- 일반 사용자 합성 데이터에서 생년/관리 버튼이 없고 `  aLiCe  ` 검색이 동작했다. 빈 목록에서는 검색어 입력 후에도 기존 등록 없음/추가 안내가 유지됐다.
- 기본 1280px 데스크톱에서 제목과 입력이 같은 행이며 관리 버튼은 오른쪽에 표시된다.
- 360px/320px에서 제목과 입력의 수직 중심이 같고, 입력 너비는 각각 약 216px/176px다. 문서의 scrollWidth가 각각 360px/320px로 가로 넘침이 없고 관리 버튼은 아래 행으로 이동한다.

## 검증 범위

브라우저 확인은 합성 데이터 미리보기이며 인증된 운영 화면 검증이 아니다. 전체 검사에서 실제 Redis/PostgreSQL 연동, 선택적 캐시 벤치마크 및 개인 리플레이처럼 별도 환경이 필요한 검사 72개는 실행하지 않았다. DB·캐시 코드 변경은 없다. 운영 배포·운영 DB·Discord·Blob·Cron은 이번 작업의 검증 범위에 포함하지 않았다.

## 독립 리뷰 및 푸시 전 검증

- 1차: 서브에이전트 3명이 검색 로직·클라이언트 경계·권한, 화면·접근성·반응형 배치, 명세·검증 기록을 나누어 독립 리뷰했다. 모두 수정이 필요한 지적 0건이었다. 로직 리뷰에서 필터·개인정보·접근제어 집중 검사 63개, 명세 리뷰에서 집중 검사 31개와 OpenSpec strict 26개를 직접 재확인했다.
- 2차: 새 서브에이전트가 전체 변경, 관련 read model과 권한 투영, 설치된 Next.js 링크 문서, CSS 및 명세를 다시 검토했으며 지적 0건을 확인했다. 리뷰에 따른 코드 수정과 미해결 지적은 없다.
- 최종 Node.js 24.21.0 `npm run check`를 다시 실행해 테스트 837개 통과·선택 검사 72개 생략, lint/typecheck/build/format 통과를 확인했다. OpenSpec strict 26개, 정식·아카이브 요구사항 일치, 완료된 작업 목록, 문서 링크 및 `git diff --check`도 통과했다.
- 리뷰 과정에서는 추가 브라우저·운영 검증을 수행하지 않았다. 브라우저 근거는 위 최초 구현의 합성 미리보기 검증이며 코드가 이후 변경되지 않았다.
