# 모임원 최근 경기 카드 검증 — 2026-10-15

## 변경

- 최근 경기 표를 승패·날짜·길이, 초상화·레벨, KDA·아이템, 양 팀 참가자의 반응형 카드로 변경했다.
- 파랑·빨강 배경과 중립색 결과 글자를 유지하고, 중복 계정·누락값·미확인 팀을 명시적으로 표시한다.
- 페이지 조회 후 해당 경기 ID들만 한 번에 보강한다. 본인의 LEVEL과 ITEM0~6만 JSON에서 추출하고 원본 JSON·PUUID·참가자 생년은 전달하지 않는다.
- 새 `member-history-v2` 캐시 키를 사용하고 상세 링크의 자동 prefetch를 비활성화했다.

## 결과

- Node 24.21.0 전체 테스트: 790 통과, 49 건너뜀. 동시 worker 수는 4로 제한했다.
- 별도 임시 로컬 Redis 7 검사: 51 통과. 새 캐시와 이전 형식 분리, 캐시 재사용 시 참가자 DB 조회 생략을 확인했다. 컨테이너는 종료·제거했다.
- 로컬 PGlite 회귀에서 2경기·4경기 페이지 모두 추가 참가자 쿼리 1회, 빈 페이지 0회를 확인했다. 바인딩된 경기 ID가 현재 페이지와 일치하며 다른 경기 참가자는 반환하지 않았다.
- 실제 리플레이 두 개를 각각 처리해 파싱한 본인 레벨·아이템과 모임원 카드 조회 결과, 참가자 수를 비교했다. 각 파일 4개 검사 통과. 실제 파일은 읽기만 했고 식별자는 출력하지 않았다.
- lint, typecheck, production build, format 통과. 임시 미리보기 경로의 잔여 개발 타입을 제거하고 타입·빌드를 다시 확인했다.
- OpenSpec 전체 strict validation: 21 통과. git diff 공백 검사 통과.
- 실제 Next 개발 서버의 카드 컴포넌트에 합성 데이터를 넣고 Riot CDN 이미지를 표시했다. 1280px에서 이미지 44개가 로드됐고, 390px·320px에서 페이지 가로 넘침이 없었다. 미리보기 경로와 서버는 제거·종료했다.

## 범위

운영 DB 쿼리 계획·지연, 인증된 운영 화면, 배포는 확인하지 않았다. 쿼리 수와 페이지 범위는 로컬 검증 결과이며 운영 성능 수치로 해석하지 않는다.
