## Why

현재 리뷰에서 신규 Discord 로그인 경합, 과거 리플레이의 닉네임 덮어쓰기, 저장 불가능한 Unicode 입력을 확인했다. 직접 검색 제출은 전체 모임원과 활성 계정을 읽으므로 데이터 증가에 따라 불필요한 DB 전송과 메모리 사용이 증가한다.

## What Changes

- 계정 등록 전에도 최신 가입 판정을 보존하고 오래된 로그인 결과를 거부한다.
- 리플레이에서 관측한 닉네임의 시각을 저장하여 과거 파일이 더 최신 표시명을 덮어쓰지 못하게 한다.
- 저장되는 리플레이 문자열과 모임원 이름에서 NUL 및 잘못된 UTF-16을 거부한다.
- 기존 NFC·trim·Unicode 소문자 규칙을 유지하는 DB 검색 컬럼과 인덱스를 추가하고 제출 검색을 DB 조건·모임원 단위 페이지 조회로 변경한다.
- 기존 데이터 마이그레이션, 영구 회귀 테스트, 실제 PostgreSQL 경합·검색 계획 검증과 운영 문서를 추가한다.

## Capabilities

### New Capabilities

- `review-correctness`: 등록 전 가입 판정 순서, 리플레이 표시명 최신성, 저장 가능한 문자열 검증.
- `indexed-exact-search`: 정규화 검색 키의 자동 유지와 DB 인덱스를 사용하는 정확 검색 및 페이지 처리.

### Modified Capabilities

없음. 기존 기능 계약을 보완하는 별도 변경이며 완료된 과거 변경 문서는 보존한다.

## Impact

인증 저장과 마이그레이션, 리플레이 파서·수집, 모임원 검증, 검색 쿼리와 DB 인덱스가 변경된다. 외부 API나 권한 모델은 바뀌지 않는다. 새 SQL 마이그레이션을 애플리케이션 배포 전에 적용해야 한다.
