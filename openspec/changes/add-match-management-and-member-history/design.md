## Context

경기 관리와 모임원별 통계는 구현되어 있다. 현재 요구사항은 [경기 관리](../../specs/match-management/spec.md)와 [모임원 전적](../../specs/member-history/spec.md)을 따른다. 이 변경은 tasks.md 4.6의 실제 브라우저 확인이 남아 있어 활성 상태로 유지한다.

## Decisions

- 경기는 제외·복구하며 참가자, 파일 해시, 원본 Blob을 보존한다. 제외 경기는 기본 목록과 모임원 집계에서 빠진다.
- 원본과 수정 경기 날짜는 시간 없는 달력 날짜다. 파일·업로드 시각은 Asia/Seoul 날짜로 변환하며 수정값을 지우면 원본 날짜를 사용한다.
- 변경은 서버에서 관리자·오너 권한, 입력과 대상 존재를 검증하고 감사 기록과 함께 저장한다.
- 모임원 전적은 현재 연결된 모든 Riot 계정의 활성 경기를 집계한다. 최근 경기 페이지와 전체 챔피언·포지션 통계는 독립적이다.
- 같은 경기에 연결 계정이 둘 이상 등장하면 중복 집계하지 않는다. 승패·K/D/A를 임의 선택하지 않고 연결 충돌을 표시한다.
- 일반 사용자에게 이름은 표시하고 생년은 전달하지 않는다.

## Remaining verification

새 목록 표시, 챔피언 요약 위치와 모바일 레이아웃의 실제 브라우저 확인은 미완료다. 이전 로컬 렌더링·통합 테스트와 과거 배포 기록은 이 확인을 대신하지 않는다. 삭제된 날짜별 검증 문서는 Git 이력에서 확인할 수 있다.
