## Why

실제로 내전 기록을 사용하려면 테스트·잘못 올린 경기를 제외하고, 파일 수정 시각으로 추정한 경기 날짜를 보정할 수 있어야 한다. 연결된 부계정까지 합친 모임원별 전적을 제공해 기록을 모으는 효용을 완성한다.

## What Changes

- 경기 제외·복구 및 제외된 경기 목록을 제공한다. 원본 리플레이와 참가자 데이터는 보존한다.
- 경기 날짜를 한국 시간 기준으로 수정하고 원본 시각으로 되돌릴 수 있게 한다. 추정·수동 수정 출처를 구분한다.
- 모임원 목록은 ‘모임원 정보’로 표시하고, 이름(생년) 링크로 상세 페이지에 이동한다. 별도의 전적 보기 링크는 제거한다.
- 개인 전적 페이지에 경기 수, 승패·승률, 평균 K/D/A와 페이지별 최근 경기를 제공한다. 연결된 라이엇 계정 위에 전체 전적 기준 챔피언별 경기 수, 승패·승률, 평균 K/D/A 요약을 제공한다.
- 제외된 경기를 기본 목록과 개인 전적 집계에서 제외하고, 계정 연결 변경과 날짜 수정 결과를 즉시 반영한다.

## Capabilities

### New Capabilities
- `match-management`: 경기 제외·복구와 원본 시각을 보존하는 날짜 보정.
- `member-history`: 연결된 Riot 계정들을 합산하는 모임원별 전적 및 경기 조회.

### Modified Capabilities

없음. 기존 MVP 변경은 아직 미아카이브 상태이며 별도 확장 기능으로 명세한다.

## Impact

Drizzle games 스키마와 추가 마이그레이션, 게임 조회·변경 함수, 인증된 Server Actions,
게임/모임원 UI 및 탐색 링크, 통합 테스트와 README를 변경한다. 신규 외부 서비스나 의존성은 필요 없다.
일괄 업로드, 임의 기간 필터, MMR·팀 편성은 후속 범위로 유지한다.
