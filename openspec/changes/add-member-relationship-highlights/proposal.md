## Why

모임원 전적에서 함께하거나 상대한 사람별 승률과 만남 횟수를 확인할 수 없다. 관계별 3경기 이상 기록을 이용해 의미 있는 상대를 빠르게 찾도록 한다.

## What Changes

- 같은 팀 최고 승률, 상대 팀 최고 승률, 가장 많이 함께한 팀원, 가장 많이 만난 상대를 모임원 단위로 집계한다.
- 플레이 포지션 아래에 최대 네 블록을 한 줄로 표시하며 값이 없는 블록과 빈 영역은 생성하지 않는다.
- 이름을 해당 모임원 전적에 연결하고 집계 캐시에 이름·계정 연결·경기 변경을 반영한다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `member-history`: 관계별 통계 집계와 조건부 단일 행 블록을 추가한다.

## Impact

회원 전적 SQL, 집계 DTO·캐시 키, 회원 상세 서버 컴포넌트와 스타일, 관련 회귀 검사 및 문서. DB 마이그레이션과 외부 API 추가는 없다.
