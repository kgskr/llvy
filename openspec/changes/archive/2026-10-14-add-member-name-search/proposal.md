> 이 디렉터리는 완료된 변경의 당시 설계·구현 기록이다. 현재 요구사항은 [주 명세](../../../specs)를 따른다. 여기에 남은 제공자·리전·인증 전환 설명은 신규 배포 지침이 아니다.

## Why

현재 메인 검색은 Riot ID만 받으므로 모임원 이름을 알고 있어도 닉네임을 따로 찾아야 한다. 같은 검색창에서 모임원 이름을 자동완성하고 선택한 사람의 전적으로 이동할 수 있게 한다.

## What Changes

- 메인 검색창에서 모임원 이름과 기존 Riot ID를 함께 검색한다. 입력 안내는 `모임원 이름 또는 롤 닉네임#태그를 입력하세요`로 바꾼다.
- 이름 접두어를 입력하면 등록된 모임원을 추천한다. 계획 기본값은 연결 계정이나 전적이 없는 모임원도 포함하는 것이다.
- 이름 후보에는 `모임원` 구분과 연결된 Riot ID를 함께 표시한다. 동명이인은 서로 다른 모임원으로 유지하고 생년을 구분 정보로 사용하지 않는다.
- 이름 후보 선택은 해당 모임원 상세로 이동한다. 직접 제출한 이름·닉네임은 정확히 일치하는 모임원이 한 명이면 이동하고, 여러 명이면 선택 목록을 표시한다.
- 기존 Riot ID 자동완성·태그 검색·저장된 검색 URL을 유지한다. Riot ID의 연결 계정·활성 경기 조건도 유지한다.
- 후보는 합계 10개까지 제공하며 같은 유형과 ID의 중복을 제거한다. 최종 검색 결과는 모임원별로 합치고 페이지를 제공해 계정 수 때문에 다른 모임원이 누락되지 않게 한다.
- 모임원 이름용 Valkey 인덱스와 기존 무효화 세대를 연결한다. 인증, 생년 숨김, 캐시 장애 시 DB 대체 조회와 현재 DB 기준의 이동 판정을 유지한다.

## Capabilities

### New Capabilities

- `member-name-search`: 이름·Riot ID 통합 입력, 유형별 자동완성 후보, 정확 일치와 동명이인 선택, 이름 인덱스·무효화·조회 권한.

### Modified Capabilities

없음. 현재 `openspec/specs/`에는 확정 spec이 없다. `add-layerbase-valkey-cache`의 검색 계약과 현재 코드를 확장하고, `replace-password-auth-with-discord`의 이름 원문 표시·생년 숨김 계약을 따른다. 기존 완료 change의 기록은 수정하지 않는다. 새 `q` 요청에서는 이름 후보의 최소 정보를 허용하므로 이전의 Riot ID 전용 자동완성 계약과 구분한다.

## Impact

- UI: 메인 페이지, 검색 폼·클라이언트 자동완성, 검색 결과·없는 사용자 안내.
- 서버: `/api/search/autocomplete`, `/search`, `nickname-search.ts`, 이름 검색/인덱스 모듈.
- 캐시: 기존 Riot ID 인덱스를 유지하면서 별도 이름 인덱스를 추가한다. 기존 모임원·계정·경기 변경의 커밋 후 세대 갱신을 재사용한다.
- 검증: 입력·API·클라이언트 응답 검증, 역할별 노출, 동명이인·동일 닉네임·다계정·빈 전적, 실제 Valkey와 브라우저 회귀.
- 문서: 개발·아키텍처·Valkey·Discord 인증 문서의 검색 계약을 갱신한다. README는 현재 간결한 구성에서 검색 설명만 필요한 만큼 수정한다.
- 신규 외부 서비스, Riot API 호출, DB 스키마 변경은 필요하지 않다. 이 change의 현재 작업 범위는 계획 작성이다.
