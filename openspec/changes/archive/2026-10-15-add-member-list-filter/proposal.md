## Why

모임원 탭에서 특정 모임원을 찾으려면 전체 카드를 직접 훑어야 한다. 이미 불러온 모임원 목록에서 이름이나 라이엇 ID에 검색어가 포함된 카드만 즉시 표시해 탐색을 줄인다.

## What Changes

- `모임원 정보` 제목과 같은 줄, 상단 모임원 메뉴 아래쪽에 검색바를 배치한다.
- 브라우저에 전달된 전체 모임원과 연결 계정만 사용해 이름 또는 라이엇 ID를 부분 일치로 필터링한다.
- 입력 변경 시 같은 페이지에서 결과를 갱신하고, 빈 검색어는 전체 목록을 복원하며 검색 결과 없음과 등록 모임원 없음을 구분한다.
- 기존 권한별 정보 표시와 모임원 상세 링크, 관리 버튼을 유지한다.

## Capabilities

### New Capabilities

- `member-list-filter`: 모임원 탭의 클라이언트 부분 일치 검색과 헤더 배치, 빈 결과 및 접근성 동작.

### Modified Capabilities

없음. 메인 검색의 서버 검색·자동완성 계약은 변경하지 않는다.

## Impact

- 모임원 페이지의 클라이언트 목록 컴포넌트와 페이지 전용 CSS.
- 검색 동작 및 권한 표시 검증, OpenSpec 정식 명세와 검증 기록.
- API, DB 쿼리, 캐시 정책, 스키마 및 의존성 변경 없음.
