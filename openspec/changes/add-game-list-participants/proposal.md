## Why

게임 목록의 인원수만으로는 누가 함께 플레이했는지 확인하기 어렵다. 선택한 팀별 두 줄형 시안을 적용해 참여자와 승리 팀을 바로 확인하고, 페이지 크기와 조회 범위를 제한한다.

## What Changes

- 게임 목록을 페이지당 10경기로 표시하고, 인원수 대신 블루·레드 팀 참여자를 두 줄로 제공한다.
- 블루·레드 팀원 영역은 각각 `#28344e`·`#59343b`로 구분한다. 날짜·진행 시간·코멘트/상세 영역은 승리 팀의 더 어두운 색(블루 `#1c263a`, 레드 `#3d242a`)을 사용하고 결과 미확인은 중립색으로 표시한다.
- 연결된 계정은 모임원 이름, 미연결 계정은 전체 라이엇 ID를 표시하며 이름 왼쪽에 챔피언 초상화를 추가한다. 정글 약어는 `JUG`로 표시한다.
- 현재 페이지의 참가자를 한 번에 조회하고 기존 인증·캐시·제외 경기 복구 기능을 유지한다.

## Impact

게임 조회·읽기 모델·목록 화면과 CSS, 회귀 테스트, OpenSpec과 검증 기록. 기존 목록 DTO와 상세 URL을 유지하고 스키마 변경 없이 구현한다.
