## 2. 서버 검색과 현재 모임원 해석

- [x] 2.1 등록 모임원 전체의 이름 검색과 최대 2개 연결 Riot ID 미리보기를 일괄 조회한다. 계정·전적 없는 모임원 포함, 생년·로그인 계정 정보 제외, N+1 없는 조회를 검증한다.
- [x] 2.2 통합 정확 일치 resolver를 구현한다. 이름과 기존 활성 경기 Riot 계정 결과를 모임원 UUID별로 합친 뒤 0명/1명/여러 명을 판정한다.

- [x] 2.4 모임원 후보 선택 후 상세의 현재 세션·존재 확인과 Riot 후보의 현재 연결 재판정을 검증한다. 이름 수정·삭제·연결 변경·DB 오류를 없는 사용자 판정과 구분한다.
